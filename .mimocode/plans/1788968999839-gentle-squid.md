# 将领贴图替换为自定义图像（方案 B：独立图像文件）

## 现状分析

将领(COMMANDER)的渲染流程分两层：

1. **战术标记层**（低缩放时）：`game.py:2455-2458` 绘制程序化几何形状（金色+阵营色圆环）
2. **贴图层**（高缩放时）：`game.py:2514` 从 `units_atlas_v2.png` 图集中按 `(faction, kind)` 切片获取

图集结构（`assets.py:62-75`）：
- 2 行 x 7 列，行 = 阵营（0=玩家, 1=敌方），列 = 兵种（0=新兵, 1=步兵...5=将领, 6=护卫）
- 将领的图集位置：**第 6 列（index=5）**，玩家=第 1 行，敌方=第 2 行

将领有额外装饰（`game.py:2527-2531`）：金色外圈 + 名字文字（"奶娃"/"豆包"）

### 修改文件：`src/mygame/rendering/assets.py`

#### 1. `__init__` 新增字段（~第 18 行附近）

#### 2. `_load()` 中在图集加载之后新增将领独立图像加载

在 `units_atlas_v2.png` 加载块之后（~第 77 行 `except` 之后），新增：

```python
# 独立将领贴图
for faction_idx, label in ((0, "ally"), (1, "enemy")):
    for suffix in ("png",):
        path = root / f"commander_{label}.{suffix}"
        try:
            source = pygame.image.load(path).convert_alpha()
            bounds = source.get_bounding_rect(min_alpha=8)
            cropped = source.subsurface(bounds).copy() if bounds.width else source
            side = max(cropped.get_width(), cropped.get_height())
            normalized = pygame.Surface((side, side), pygame.SRCALPHA)
            normalized.blit(cropped, cropped.get_rect(center=normalized.get_rect().center))
            self._commander_sources[faction_idx] = normalized
            break
        except (FileNotFoundError, pygame.error, ValueError):
            continue
# 如果敌方文件不存在，回退使用玩家的
if 1 not in self._commander_sources and 0 in self._commander_sources:
    self._commander_sources[1] = self._commander_sources[0]
```

#### 3. 修改 `unit()` 方法（~第 124 行）

在获取 source 之前，先检查独立将领贴图：

```python
def unit(self, faction: int, kind: int, size: int) -> pygame.Surface | None:
    # 优先使用独立将领贴图
    if kind == 5:  # COMMANDER
        source = self._commander_sources.get(faction)
        if source is not None:
            size = max(4, size)
            key = (-1, faction, size)  # 用 -1 区分独立贴图缓存
            if key not in self.unit_cache:
                self.unit_cache[key] = pygame.transform.smoothscale(source, (size, size))
            return self.unit_cache[key]
    # 回退到图集切片
    source = self.unit_sources.get((faction, kind))
    ...（后续逻辑不变）
```

### 用户放置图像

将自定义图像放到 `assets/generated/` 目录：
- `commander_ally.png` — 玩家将领
- `commander_enemy.png` — 敌方将领（可选，不存在时回退使用 ally）

建议图像：正方形、带透明通道、尺寸 64x64 或 128x128。

## 验证方式

1. 启动游戏，进入战斗场景
2. 缩放到高倍率（zoom > 0.42），确认将领显示新贴图而非图集默认贴图
3. 检查玩家将领和敌方将领分别显示正确图像
4. 确认金色外圈和名字文字仍正常显示
5. 低缩放时仍显示战术标记（不改动此部分）
6. 不放置图像文件时，游戏回退到原有图集贴图（向后兼容）
