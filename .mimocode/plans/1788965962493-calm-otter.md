# 实现计划：将领贴图改为奶娃/豆包

## 目标
- 我方将领（faction 0, kind=5）→ 奶娃（黄色圆胖小龙）
- 敌方将领（faction 1, kind=5）→ 豆包AI（暖白色可爱女孩）
- 贴图大小保持不变

## Atlas 位置
`assets/generated/units_atlas_v2.png`（2032×774，每格 ~290×387）
- Column 5, Row 0 → (1450, 0) → 奶娃
- Column 5, Row 1 → (1450, 387) → 豆包

## 视觉设计

### 奶娃（我方 — 黄色圆胖小龙）
- 主色：明亮黄色 `(255, 210, 50)`，深黄轮廓 `(180, 140, 20)`
- 圆大脑袋占身体 60%，头身比 ~1.5:1
- 大圆黑眼睛 + 小微笑嘴巴
- 头顶两个小圆角（龙角）
- 胖嘟嘟圆润身体，无尖锐棱角
- 腮红 `(255, 170, 130)`
- 小短手小短脚
- 整体居中于 290×387 cell 内，约 200×300 像素

### 豆包AI（敌方 — 暖白可爱女孩）
- 主色：暖白 `(240, 245, 255)`，轮廓 `(140, 160, 200)`
- 圆脸，柔和轮廓
- 大圆眼睛 + 甜美微笑
- 头部有小豆芽/豆荚装饰作为识别元素
- 浅蓝 `(160, 200, 240)` 头饰/衣服
- 浅粉色 `(255, 200, 210)` 腮红
- 短发造型
- 整体居中于 cell 内，约 200×300 像素

## 修改文件

### `scripts/generate_assets.py`
添加 `_paint_commander_sprites()` 函数：
1. 加载 `units_atlas_v2.png`
2. 清空 column 5 两个 row（填透明）
3. 用 `pygame.draw` 逐像素/逐形状绘制奶娃（row 0）
4. 用 `pygame.draw` 逐像素/逐形状绘制豆包（row 1）
5. 保存覆盖原文件

在 `main()` 中 sprites() 之后调用。

### 不需要修改
- `rendering/assets.py` — 加载逻辑已正确处理 atlas column 5
- `app/game.py` — fallback 战术标记保持原样

## 验证
1. `python scripts/generate_assets.py`
2. `python -m mygame` → 开始对局
3. zoom > 0.58：确认奶娃/豆包显示
4. zoom 0.42~0.58：确认淡入过渡
5. zoom < 0.42：确认战术标记正常
6. 确认其他兵种贴图未变
