# 自制素材许可台账

`assets/generated/terrain.png`、`assets/generated/units.png` 与 `assets/audio/*.wav` 由本仓库的 `scripts/generate_assets.py` 程序化生成，项目作者将其作为本项目自有素材发布；不含第三方图像或录音。

`assets/generated/terrain_atlas.png` 与 `assets/generated/units_atlas.png` 于 2026-09-08 使用 OpenAI 图像生成工具为本项目定制生成。两张图均不含商标、文字或第三方现成素材；项目内将其作为可替换的第一版美术图集使用。

`assets/generated/bridge.png` 与 `assets/generated/tower.png` 于 2026-09-08 使用 OpenAI 图像生成工具为本项目定制生成，均为透明背景的俯视像素设施素材。生成要求限定为单一原创桥梁/防御塔，不包含文字、商标或第三方角色。

`assets/generated/village.png` 与 `assets/generated/effects_atlas.png` 于 2026-09-08 使用 OpenAI 图像生成工具为本项目定制生成。前者是透明背景的中世纪村庄聚落，后者包含斩击、受击、疾跑和冲锋四类透明特效；均不包含文字、商标、水印或第三方角色。

`assets/generated/units_atlas_v2.png` 于 2026-09-09 使用 OpenAI 图像生成工具为本项目定制生成，包含蓝、红双方的预备兵、步兵、侦察兵、工兵、刺客、将领和护卫十四个透明背景人物。它不包含文字、商标、水印或第三方角色，并作为运行时优先加载的人物图集。

`assets/fonts/NotoSansSC.ttf` 是唯一第三方美术资源，来源、作者和 SIL Open Font License 1.1 已记录在根目录 `THIRD_PARTY_LICENSES.md` 与 `assets/fonts/OFL.txt`。
