# 指挥官战术对抗

俯视角、即时制、千人独立模拟的单人指挥官战术游戏。完整需求见 [myplan.md](myplan.md)。

汇报 PPT、项目报告、代码导读与课程提交包等交付材料见 [docs/](docs/README.md)。

初始战场由可复现种子生成：中央河流在 4–12 格宽之间变化，草场、森林、沼泽与道路构成不同速度和视野路线，六座对称村庄分别承担后方补给、林区争夺和前沿冲突目标。

## 开发运行

```bash
python3.12 -m venv .venv
.venv/bin/pip install -e '.[dev,voice]'
.venv/bin/mygame
```

没有语音依赖或 DeepSeek 密钥时，鼠标、键盘和本地中文规则命令仍可完成对局。可选的大模型解析只读取环境变量：

```bash
export DEEPSEEK_API_KEY='...'
export DEEPSEEK_MODEL='deepseek-v4-flash'
```

## 操作

- WASD / 中键拖动：摄像机；滚轮或战场右上角 `+ / −`：平滑缩放
- 左键 / 框选：选择；右键：打开地形菜单，可移动、攻击移动或调度工兵建设
- 底栏“全军 / 将领 / 工兵 / 侦察 / 预备”可直接用鼠标选择部队；选中预备兵后可点击训练为四种正式兵种
- 村庄内有己方单位时，右键村庄可征召 20 名预备兵；新兵会自动选中并显示训练入口
- 河流宽度会自然变化；探明两岸后右键河面可预览桥梁跨度与工程量，桥会自动对齐并跨到两侧岸上；塔位附近的工兵会自动进驻为守塔弓箭手
- 缩略图：点击或按住拖动切换视野，在图内滚轮或点击 `+ / −` 缩放
- 顶栏“自动开 / 自动关”切换自动作战，开启后仍可随时下达手动命令
- Ctrl+1–9：编组；1–9：选择编组；Shift：追加命令
- 方向键：直接移动将领；V：按住说话；Enter：文字命令
- Space：暂停；- / +：速度；F1：指令书；F5：保存；F9：载入
- F11：切换全屏；窗口尺寸可自由调整
- 回放中 F2 / F3 / F4：玩家 / 敌方 / 全局视角；左右方向键跳转 5 秒
- 不使用键盘时，可通过战斗顶栏和暂停/帮助面板完成暂停、调速、保存、载入、全屏与军令输入；战场选择和移动继续使用左右键。

游戏的像素战场以 `1280×720` 逻辑网格绘制，再用最近邻算法等比适配窗口或桌面分辨率；
文字会在最终显示分辨率上重新绘制，因此高分屏既保留像素边缘，也能显示清晰的中文和 UI 标签。黑色迷雾会被经过的部队
永久擦除，敌军进入任何已探索区域都会显示。未探索区右键不会泄露真实地形，移动命令也不会被隐藏河流提前拒绝。陆军不能直接涉水，徒步跨河前必须先完成桥梁，并会严格沿桥面通行。
村庄、桥梁、防御塔和近景单位使用独立像素贴图；人物在远景切换为按兵种区分形状的阵营色战术符号，近景显示完整人物，不再用黑色光晕标记敌方。斩击、弹道、受击、冲锋和疾跑提供短促战斗反馈，将领阵亡会先聚焦战场位置再进入结算。

离线标准文字命令示例：

- `第一侦察队前往北部中央`
- `20名初始兵分化为工兵`
- `工兵队在中央架桥`
- `第1组守住最近村庄`
- `第一战团集火敌方将领`
- `20名步兵编为第6组 命名为河西守军`
- `第6组进入防御塔`、`第6组离开防御塔`
- `第1组登船`、`船只前往西岸`、`第1组下船`

在线解析失败时战局自动暂停：`R` 最多重试一次，`O` 切换离线，`Q` 创建紧急存档并退出。语音模型首次下载必须在游戏提示后按 `Y` 明确确认。

## 验证

```bash
.venv/bin/pytest
.venv/bin/ruff check .
.venv/bin/mypy src/mygame
.venv/bin/python -m mygame --headless --ticks 400
.venv/bin/python scripts/benchmark_soak.py --ticks 24000
```

程序化占位资源可重复生成；正式地形和单位图集位于 `assets/generated/`，运行时缺失会自动回退到占位图形：

```bash
.venv/bin/python scripts/generate_assets.py
```

存档、回放、设置和轮换日志分别写入 `platformdirs` 返回的用户数据/日志目录。存档与回放使用带版本魔数的 MessagePack + Zstandard 容器、原子替换和单份备份。

## 原生发行包

Windows 与 Linux 必须分别在对应系统构建：

```bash
.venv/bin/pyinstaller --noconfirm CommanderTacticalArena.spec
dist/CommanderTacticalArena/CommanderTacticalArena --headless --ticks 10
```

`.github/workflows/release.yml` 会在 Ubuntu 22.04 x64 与 Windows x64 上分别打包、冒烟测试并上传目录式发行包。语音依赖及模型保持可选，不进入基础发行包；源码安装 `.[voice]` 后可启用本地转写。
