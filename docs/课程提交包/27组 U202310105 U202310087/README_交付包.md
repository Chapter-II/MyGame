# 指挥官战术对抗 · 交付包

## 文档
- 项目报告.pdf — 可直接转发的项目说明
- 答辩PPT.pptx / 项目汇报.pptx — 汇报演示
- 答辩稿.pdf / 项目汇报摘要.pdf — 配套文字材料

## 源码
- src/mygame — 主程序
- tests — 单元/集成/性能测试
- pyproject.toml — 依赖与工具配置

## 运行
1. Python 3.12 建虚拟环境
2. pip install -e "".[dev]""
3. python -m mygame  或  启动游戏.bat

在线能力（可选）：复制 配置/local.env.example 为项目根目录 local.env 并填入密钥。
请勿将真实密钥提交到仓库。
