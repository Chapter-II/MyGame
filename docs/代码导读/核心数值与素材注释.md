## 1. 玩法魔法数字：`src/mygame/constants.py`

战斗、碰撞、编队等「不好写进 TOML 的几何/阈值」集中在这里，避免散落在业务代码里。

```python
# ── 战斗 ──────────────────────────────────────────────
MELEE_RANGE_THRESHOLD: int = 30   # 攻击距离 ≤30 视为近战（像素）
MAX_MELEE_ENGAGEMENTS: int = 6    # 同一目标最多 6 人围攻，避免无限叠人
CHASE_DISTANCE: float = 180.0     # 攻击移动时最多追出的距离
COMBAT_CELL_SIZE: float = 64.0    # 找敌人时空间哈希格子大小（越大越省算力、越粗）

# ── 设施 ──────────────────────────────────────────────
BRIDGE_RADIUS: float = 160.0              # 架桥交互半径
BRIDGE_DECK_HALF_WIDTH: float = 36.0      # 桥面可通行半宽（防止掉河里）
BUILD_PROXIMITY: float = 48.0             # 工兵靠近多少内才能开工

# ── 阵型 ──────────────────────────────────────────────
FORMATION_SPACING: float = 18.0   # 移动命令时单位间距，避免全挤一点
ARRIVAL_DISTANCE: float = 1.0     # 距目标多少算「到达」

# ── 开局兵力构成（不含将领+4护卫）────────────────────

COMPOSITION_SCOUT: int = 60
COMPOSITION_ENGINEER: int = 50

```

**怎么改：** 想让围攻更挤、桥更宽、开局侦察更多，直接改这些常量后跑 `pytest` 即可。

## 2. 数值策划主表：`config/data/balance_v1.toml`

兵种、地形、设施、AI 难度都在这份 TOML 里，**改平衡优先改这里**，不用动 Python。

### 2.1 世界与节奏

```toml
[world]
width = 4096          # 战场宽（像素）
height = 2304         # 战场高
tile_size = 32        # 一格地形 32px → 约 128×72 格
simulation_hz = 20    # 每秒模拟 20 帧（固定时间步）
default_army_size = 500
```

### 2.2 兵种（举例：步兵 vs 侦察 vs 刺客）

```toml
[units.infantry]
hp = 120.0            # 肉厚，正面主力
damage = 16.0
attack_interval = 1.2 # 秒/次
speed = 24.0
vision = 220.0        # 视野
detection = 64.0      # 反隐（能发现多近的刺客）

[units.scout]
hp = 70.0             # 脆，但
speed = 39.0          # 最快
vision = 420.0        # 视野最大 → 开图用
detection = 220.0     # 最容易发现刺客

[units.assassin]
hp = 55.0
damage = 45.0         # 爆发最高
attack_interval = 1.8 # 但攻速慢
speed = 31.0
attack_range = 16.0
```

设计直觉：**步兵站桩、侦察开图、刺客秒人**，全部靠这几行数字拉开手感差异。

### 2.3 地形速度 / 视野倍率

```toml
[terrain.speed]
plain = 1.0     # 平原：标准速度
forest = 0.6    # 森林：约慢 40%
swamp = 0.4     # 沼泽：约慢 60%
road = 1.1      # 道路：略快，鼓励修路
river = 0.2     # 陆军几乎不能走（逻辑上还会硬拦）

[terrain.vision]
forest = 0.5    # 森林里视野减半 → 适合伏击
grass = 0.75    # 高草衰减远距离视野
```

### 2.4 工程设施

```toml
[facilities.bridge]
work = 600.0              # 工程量
minimum_engineers = 8     # 最少 8 工兵才能开工

[facilities.tower]
work = 800.0
minimum_engineers = 10

[facilities]

```

### 2.5 战术（全速 / 冲锋）


## 3. 配置如何被程序读入：`config/loader.py`

```python
class UnitStats(BaseModel):
    """用 Pydantic 校验 TOML，写错类型/负数会直接启动失败。"""
    hp: float = Field(gt=0)
    damage: float = Field(ge=0)
    speed: float = Field(gt=0)
    vision: float = Field(gt=0)
    # ...

def load_balance() -> BalanceConfig:
    path = files("mygame.config").joinpath("data/balance_v1.toml")
    with path.open("rb") as handle:
        raw = tomllib.load(handle)          # 标准库读 TOML
    units = {name: UnitStats(**values) for name, values in raw["units"].items()}
    # terrain_speed / facilities / ai 同样拆开塞进 BalanceConfig
    return BalanceConfig(world=..., units=units, ...)
```

**要点：**

1. 数值**只进 TOML**，业务代码读 `world.balance.units["infantry"].hp` 这类字段。  
2. `frozen=True`：配置加载后不可改，避免运行中被意外写坏。  
3. 非法数值（如 `hp = -1`）在启动时就会报错，而不是打到一半崩。

## 4. 贴图素材怎么引用：`rendering/assets.py`

素材目录：`assets/generated/`（可由 `scripts/generate_assets.py` 再生）。  
**没有贴图也能玩**：加载失败会打日志，并回退到程序化颜色/战术符号。

### 4.1 找资源根目录

```python
@staticmethod
def _asset_root() -> Path | None:
    roots = [Path(__file__).resolve().parents[3], Path.cwd()]
    bundle_root = getattr(sys, "_MEIPASS", None)  # PyInstaller 打包后的临时目录
    if bundle_root:
        roots.insert(0, Path(bundle_root))
    for root in roots:
        generated = root / "assets" / "generated"
        if generated.exists():
            return generated
    return None   # 找不到 → 全部走占位图形
```

### 4.2 图集切片（Atlas）

一张大图切成小块，比加载几十个小文件快：

```python
# 地形：terrain_atlas.png 切成 3 列 × 2 行 = 6 种地形
atlas = pygame.image.load(root / "terrain_atlas.png").convert_alpha()
cell_w, cell_h = atlas.get_width() // 3, atlas.get_height() // 2
for row in range(2):
    for col in range(3):
        self.terrain_sources.append(
            atlas.subsurface((col * cell_w, row * cell_h, cell_w, cell_h)).copy()
        )

# 单位：units_atlas_v2.png，上半我军 / 下半敌军，横向 7 兵种
# 索引 (faction, kind) → 贴图；再裁透明边、居中方形，方便缩放
```

| 文件 | 用途 |
|------|------|
| `terrain_atlas.png` | 6 种地形块 |
| `units_atlas_v2.png` | 2 阵营 × 7 兵种 |
| `commander_ally.png` / `commander_enemy.png` | 将领独立立绘 |
| `bridge.png` / `tower.png` / `village.png` | 设施与村庄 |
| `effects_atlas.png` | 斩击/受击/疾跑/冲锋 特效 |

### 4.3 失败回退

```python
try:
    atlas = pygame.image.load(root / "terrain_atlas.png").convert_alpha()
except (FileNotFoundError, pygame.error, ValueError):
    logger.info("地区纹理图集不可用，使用程序化颜色回退", exc_info=True)
    # terrain_sources 保持为空 → 绘制层画色块
```

**要点：** 素材是「增强」不是「硬依赖」；缺文件不会导致无法启动。

### 4.4 缩放缓存

```python
def unit(self, faction: int, kind: int, size: int) -> pygame.Surface | None:
    source = self._commander_sources[faction] if kind == 5 else self.unit_sources.get((faction, kind))
    key = (faction, kind, size)
    if key not in self.unit_cache:
        self.unit_cache[key] = pygame.transform.smoothscale(source, (size, size))
    return self.unit_cache[key]   # 同尺寸只缩放一次
```

镜头缩放时同一尺寸会反复请求，**用字典缓存**避免每帧 `smoothscale`。

## 5. 行为总览：命令 → 模拟 → 画面

```
玩家鼠标 / 文字 / 语音 / 本地 AI
              │
              ▼ 只能提交结构化命令 CommandEnvelopeV1
        World.execute()     校验并改「意图」
              │
              ▼
        World.step()        固定 20Hz 推进世界
              │  移动 → 碰撞 → 桥面约束 → 战斗 → 工程 → 胜负 → 迷雾
              ▼
   结果消息 + GameEvent  ──►  HUD / 存档 / 回放
```

| 原则 | 一句话 |
|------|--------|
| 命令单向驱动 | 输入层不能直接改单位坐标 |
| 配置数据驱动 | 数值在 TOML，业务只读 |
| 分频更新 | 碰撞/战斗/迷雾不必每帧算 |
| AI 只读快照 | 公平靠 ObservationSnapshot |

## 6. 命令入口：`simulation/world.py` → `execute`

```python
def execute(self, command: CommandEnvelopeV1) -> CommandResultV1:
    # 1) 过期检查：网络/大模型返回太晚就作废
    if self.tick - command.issued_tick > self.balance.world.simulation_hz * 10:
        return self._result(command, CommandStatus.EXPIRED, "command_expired", "指令已过期")

    payload = command.payload
    # 2) 按 kind 分发到具体处理函数
    if isinstance(payload, MovePayloadV1):
        result = self._execute_move(command, payload)      # 移动/攻击移动
    elif isinstance(payload, BuildPayloadV1):
        result = self._execute_build(command, payload)     # 桥/船/路/塔
    elif isinstance(payload, ConvertPayloadV1):
        result = self._execute_convert(command, payload)   # 兵种分化
    # ... 编组、征兵、登塔、冲锋等同理

    # 3) 只有真正接受的命令才进回放日志
    if result.status == CommandStatus.ACCEPTED:
        self.command_log.append(command)
    return result
```

**读代码时注意：**

- `REJECTED` 会带中文 `message_zh`，指挥面板直接显示。
- 移动命令还会查：目标是不是无桥河格？路上有没有完整桥？——用的是**本阵营已知**地形，不是上帝视角。

## 7. 主循环：`World.step`（固定时间步）

```python
def step(self, steps: int = 1) -> None:
    for _ in range(steps):
        self._update_timers()            # 攻击冷却、战术剩余时间、耐力恢复
        self._move_units()               # 沿流场/目标点推进
        if self.tick % 5 == 1:
            self._resolve_collisions()   # 碰撞分频：不必每帧
        self._constrain_units_to_bridge_decks()   # 桥面矩形约束
        self._restore_illegal_river_entries()     # 误入河格拉回
        if self.tick % 4 == 0:
            self._resolve_combat()       # 战斗分频
        self._update_engineering()       # 工兵施工进度
        self._auto_garrison_towers()     # 工兵自动驻塔
        self._check_victory()            # 将领死亡 → 结束
        if self.tick % 10 == 0:
            self._perception.update(self)  # 迷雾与敌军可见性
        self.tick += 1
```

**为什么分频？** 500×500 每帧全量算碰撞会卡；隔几帧算一次，玩家几乎感觉不到，帧率却稳很多。

## 8. 战争迷雾：`perception/fog.py`

```python
class FogOfWar:
    def __init__(self, rows, cols, tile_size):
        # 两个阵营各一份「已探索」格子图
        self.explored = np.zeros((2, rows, cols), dtype=np.bool_)

    def update(self, world: World) -> None:
        for faction in (Faction.PLAYER, Faction.ENEMY):
            active = world.units.active(faction)
            # 视野半径 × 地形衰减（森林 0.5、高草 0.75…）
            radii = ceil(units.vision[active] * vision_table[terrain] / tile_size)
            for row, col, radius in unique_cells:
                self._reveal_cells(faction, row, col, radius)
            # 永久探索：揭开就不再变黑
            self.explored[faction] |= self.visible[faction]
```

**要点：**

- 部队经过像橡皮擦，区域永久可见。
- 敌军**只在已探索区**写入 history，离开就从界面消失。
- 未探索区右键不会显示真实地形（只给通用「移动」）。

## 9. 流场寻路：`simulation/navigation.py`

千人**不**各自跑 A*，而是按目标缓存一张方向场：

```python
class FlowFieldCache:
    def get(self, target_x, target_y, movement="land") -> FlowField:
        key = (col, row, movement, self.map.revision)
        if key not in self.cache:
            self.cache[key] = self._build(col, row, movement)  # Dijkstra 积分场
        if len(self.cache) > 48:
            self.cache.pop(next(iter(self.cache)))  # 简单上限
        return self.cache[key]

    def set_bridges(self, bridges, radius):
        """只有已完成桥梁盖住的河格，陆军才可走（矩形桥面判定）"""
```

单位每帧只查自己所在格的方向向量 → O(1) 级取向，性能关键点。

## 11. 本地双层 AI：`ai/local.py`

```python
_DIFFICULTY_PROFILES = {
    "normal": {
        "strategy_interval_ticks": 40,   # 约 2 秒定一次目标/分兵
        "tactical_interval_ticks": 5,    # 约 0.25 秒处理接敌/撤退
        "aggression": 0.7,
        "retreat_hp_ratio": 0.25,        # 血量低于 25% 后撤
    },
}

class LocalStrategicAI:
    def decide(self, observation: ObservationSnapshotV1) -> list[CommandEnvelopeV1]:
        commands = []
        if self._tactical_ready(observation.tick):
            commands.extend(self._tactical_decisions(observation))
        if self._strategy_ready(observation.tick):
            commands.extend(self._strategic_decisions(observation))
        return commands[: int(self.config["max_simultaneous_tasks"])]
```

**公平性：** `decide` 只接受迷雾过滤后的快照，输出也是 `CommandEnvelope`，和玩家同一条执行路径。

## 12. 语音识别管线：`input/voice.py` + `app/game.py`

```
按住 V（或点底栏「语音」）
    → 过短 / 太轻 → 直接忽略
    → 优先在线 ASR（DeepSeek 或 SPEECH_API_KEY）
    → 失败 / 空结果 → 本地 faster-whisper
    → 文本 → 规则解析 →（可选）DeepSeek 军令
```

```python
def _transcribe_voice_samples(self, samples: bytes) -> str:
    if self.online_enabled and self.speech.online.available:
        try:
            text = self.speech.online.transcribe(samples, ...)
            if text:
                return text
        except VoiceUnavailable as exc:
            logger.warning("online speech failed, falling back to local: %s", exc)
    return self.whisper.transcribe(samples, ...)
```

在线密钥写在根目录 `local.env`（已 gitignore），启动时自动加载。
