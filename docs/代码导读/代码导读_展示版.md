## 1. 一分钟看懂项目骨架

```
玩家 / AI / 语音
        │  只能提交「结构化命令」
        ▼
   CommandEnvelopeV1
        │
        ▼
 World.execute()  ──►  World.step()  固定 20Hz 推进
        │                    │
        │                    ├─ 移动 / 碰撞 / 战斗
        │                    ├─ 工程 / 船 / 塔
        │                    └─ 迷雾更新（分频）
        ▼
  CommandResultV1 + GameEvent   ──►  UI / 存档 / 回放
```

核心原则：

| 原则 | 含义 |
|------|------|
| 命令单向驱动 | 输入和 AI 不能直接改单位 |
| 配置数据驱动 | 数值在 TOML，不写死在业务里 |
| 素材可缺失 | 贴图失败自动回退占位图 |
| AI 只读快照 | 公平靠 ObservationSnapshot，不靠自觉 |

## 4. 命令协议与执行入口

### 协议（`protocols.py`）

```python
class CommandEnvelopeV1(ProtocolModel):
    command_id: str
    faction: Faction
    issued_tick: int          # 发出帧，用于过期检查
    source: CommandSource     # mouse / text / voice / local_ai
    payload: CommandPayloadV1 # 带 kind 判别字段

class ObservationSnapshotV1(ProtocolModel):
    own_units: tuple[...]
    visible_enemies: tuple[...]   # 不含迷雾外敌军
    known_terrain: bytes          # 仅已探索
```

### 执行入口（`simulation/world.py`）

```python
def execute(self, command: CommandEnvelopeV1) -> CommandResultV1:
    # 异步返回过晚 → 直接作废，避免幽灵指令
    if self.tick - command.issued_tick > self.balance.world.simulation_hz * 10:
        return self._result(command, CommandStatus.EXPIRED, "command_expired", "...")

    if isinstance(payload, MovePayloadV1):
        result = self._execute_move(command, payload)
    elif isinstance(payload, BuildPayloadV1):
        result = self._execute_build(command, payload)
    # ...

    if result.status == CommandStatus.ACCEPTED:
        self.command_log.append(command)   # 回放只记结构化命令
    return result
```

## 5. 固定时间步主循环

```python
def step(self, steps: int = 1) -> None:
    for _ in range(steps):
        self._update_timers()           # 冷却 / 耐力
        self._move_units()
        if self.tick % 5 == 1:
            self._resolve_collisions()  # 分频：不必每帧
        self._constrain_units_to_bridge_decks()
        if self.tick % 4 == 0:
            self._resolve_combat()
        self._update_engineering()
        self._check_victory()
        if self.tick % 10 == 0:
            self._perception.update(self)   # 迷雾分频
        self.tick += 1
```

要点：渲染与模拟解耦；碰撞/战斗/感知分频，支撑千人规模。

## 6. 战争迷雾

```python
class FogOfWar:
    def __init__(self, rows, cols, tile_size):
        self.explored = np.zeros((2, rows, cols), dtype=np.bool_)  # 两阵营各一份

    def update(self, world):
        for faction in (Faction.PLAYER, Faction.ENEMY):
            # 按单位视野 × 地形衰减揭图
            radii = ceil(units.vision * vision_table[terrain] / tile)
            self._reveal_cells(faction, row, col, radius)
            self.explored[faction] |= self.visible[faction]   # 永久保留
```

要点：部队经过像橡皮擦；离开探索区的敌军从界面消失；未探索区不泄露真实地形。

## 9. 本地双层 AI

```python
_DIFFICULTY_PROFILES = {
    "normal": {
        "strategy_interval_ticks": 40,    # ~2s 战略
        "tactical_interval_ticks": 5,     # ~0.25s 战术
        "aggression": 0.7,
        "retreat_hp_ratio": 0.25,
    },
}

class LocalStrategicAI:
    """只接受 ObservationSnapshot，输出也是 CommandEnvelope。"""
    def decide(self, observation):
        commands = []
        if self._tactical_ready(observation.tick):
            commands.extend(self._tactical_decisions(observation))
        if self._strategy_ready(observation.tick):
            commands.extend(self._strategic_decisions(observation))
        return commands[: self.config["max_simultaneous_tasks"]]
```

要点：与玩家同一执行路径，便于审计是否偷看迷雾。

## 10. 语音识别管线

```
按住 V 采音
    → 过短 / 静音直接丢弃
    → 优先在线（DeepSeek 或 SPEECH_API）
    → 失败自动回落本地 Whisper
    → 文本进入规则解析 / DeepSeek 军令
```

```python
def _transcribe_voice_samples(self, samples: bytes) -> str:
    if self.online_enabled and self.speech.online.available:
        try:
            text = self.speech.online.transcribe(samples, ...)
            if text:
                return text
        except VoiceUnavailable as exc:
            logger.warning("online speech failed, falling back to local: %s", exc)
    return self.whisper.transcribe(samples, ...)
```
