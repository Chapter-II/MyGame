# DESIGN.md — 项目汇报 PPT

## Style anchor
夜间指挥所战术沙盘（项目自身 DESIGN.md「午夜军令台」）：克制、可信、信息密但有秩序。参考现代军工/战略简报风格，避免花哨装饰。

## Palette
- 背景：`#0B1220`（近深夜幕）
- 面板：`#152033`（军令台面）
- 墨色：`#E8EEF7`（冷白正文）
- 次要文字：`#8B9BB4`
- 强调钴蓝：`#3B82F6`
- 警戒琥珀：`#D97706`
- 敌情珊瑚：`#E85D4C`
- 友军青：`#2DD4BF`

## Typography
- 中文：Microsoft YaHei / Noto Sans CJK SC
- 拉丁/数字：Segoe UI
- 标题 32–36pt Bold；副标题 16–18pt；正文 14–16pt；统计大数 40–54pt

## Layout
- 16:9（13.333 × 7.5 in）
- 边距 0.55in；双栏或三卡片网格；底部细线页脚含页码
- 每页一个论点；标题即结论

## Slide manifest
1. 封面：项目名 + 一句话定位 + 汇报日期
2. 项目背景：做什么、给谁、核心机制
3. 产品定位：差异化主张与体验原则
4. 关键进展时间线：2026-09-07 → 09-09
5. 已交付能力：玩法 / 指挥 / 工程 / 系统
6. 技术与质量：架构分层、测试与发行
7. 风险与应对：表格式
8. 下一步计划：阶段 8–9 与验收清单
9. 结尾：当前状态一句话 + 关键数字

## Image manifest
- 封面：本地 `assets/generated/commander_ally.png` 或 `main_menu.png`（产品实拍/生成资源）
- 其余页：L1 形状/图标/时间线，不额外生成图
